# ⏳ تاريخ كل حاجة

موقع عربي (بلهجة مصرية) بيحكي تاريخ **كل حاجة**: من الانفجار العظيم لحد النهاردة. HTML + CSS + JavaScript بس، من غير أي build ولا مكتبات خارجية.

## الأقسام
- **🕰️ الخط الزمني:** أكتر من 170 حدث مقسمين على 8 عصور، مع بحث (بيفهم الإسكندرية = اسكندريه) وفلتر بالفئة وفلتر «مصر» وزرار «حدث عشوائي».
- **🌌 السنة الكونية:** عمر الكون (13.8 مليار سنة) مضغوط في سنة واحدة، وكل ثانية فيها حوالي 438 سنة. كل التاريخ المكتوب بيطلع في آخر حوالي 12 ثانية.
- **📅 النهاردة في التاريخ:** إيه اللي حصل في أي يوم في السنة، ولو اليوم فاضي بيعرض أقرب أيام فيها أحداث.
- **🧠 اختبر نفسك:** 10 أسئلة عشوائية («إمتى حصل؟» و«أيهم حصل الأول؟»)، وبيحفظ أعلى نتيجة في المتصفح.
- **⚖️ قارن:** اختار أي حدثين واعرف كام سنة بينهم، مع معلومة عن كليوباترا والهرم والقمر بتتحسب من البيانات.

## التشغيل
```bash
python3 -m http.server 8000
# افتح http://localhost:8000
```
النشر: **Settings ← Pages ← Deploy from a branch ← `main` / `(root)`**

## هيكل المشروع
```
index.html        الصفحة
history/style.css التصميم
history/data.js   الفئات + الأحداث الأساسية
history/more.js   أحداث إضافية (بتتضاف على data.js)
history/util.js   المنطق: ترتيب، تنسيق التواريخ، السنة الكونية، الاختبار (من غير DOM)
history/app.js    الواجهة والتنقل
tests/            اختبارات المنطق والبيانات + اختبار شامل في متصفح حقيقي
```

## إضافة حدث
زوّد سطر في `history/more.js` بنفس الشكل:
```js
E("sci", "ce", 1969, "🌕", "العنوان", "الشرح باختصار", { md: "07-20", eg: false, approx: false, cosmic: false })
```
- نوع الوقت: `bya` مليار سنة · `mya` مليون سنة · `kya` ألف سنة · `bce` قبل الميلاد · `ce` ميلادي
- `md` = «شهر-يوم» لو التاريخ الدقيق معروف (بيظهر الحدث في «النهاردة في التاريخ»)
- `approx` = التاريخ تقريبي · `eg` = متعلق بمصر · `cosmic` = يظهر في «السنة الكونية»
- الفئات: `cosmos life human civ war sci tech art sport food`

بعد الإضافة شغّل `npm test`: بيتأكد إن الفئة والتاريخ والعنوان سليمين ومفيش تكرار.

## الاختبارات

npm test          # منطق وبيانات (Node بس)

## ملاحظات عن الدقة
- التواريخ القديمة جداً تقريبية وعليها «حوالي».
- التواريخ اللي قبل 1582 مكتوبة بالشكل المتعارف عليه في كتب التاريخ (التقويم اليولياني).
- لو لقيت معلومة غلط، صلّحها في `history/data.js` أو `history/more.js` وشغّل الاختبارات.
